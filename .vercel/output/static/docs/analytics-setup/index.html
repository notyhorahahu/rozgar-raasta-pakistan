Google Analytics 4 (GA4)

  1. Go to analytics.google.com and sign in with the owner's Google account.
  2. Create a property named "Rozgar Raasta Pakistan".
  3. Choose "Web" and enter the live URL https://rozgar-raasta-pakistan.vercel.app.
  4. Copy the Measurement ID (it looks like G-XXXXXXXXXX).
  5. Add it to the site configuration and include the GA4 snippet in src/layouts/BaseLayout.astro inside <head>.
  6. Verify in GA4 Realtime that a visit to the live site is recorded.

Do not invent a Measurement ID. Until a real one is added, the admin dashboard honestly shows "Traffic — not connected".

Google Search Console

  1. Go to search.google.com/search-console and sign in.
  2. Add the property https://rozgar-raasta-pakistan.vercel.app (URL prefix).
  3. Verify ownership using the HTML-tag method (add the verification meta tag to BaseLayout.astro) or the DNS method.
  4. Submit the sitemap: https://rozgar-raasta-pakistan.vercel.app/sitemap-index.xml.
  5. Request indexing for the homepage and main category pages.
  6. Monitor Search impressions, clicks and coverage issues weekly.
