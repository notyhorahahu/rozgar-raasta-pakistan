# Branded Graphics System — Rozgar Raasta Pakistan

Self-contained HTML/CSS templates. Open in a browser, edit the text, and screenshot / export at the stated size. No external images, no fake logos, no government emblems.

| File | Use | Size |
|------|-----|------|
| `pin-vertical.html` | Pinterest Pin | 1000 × 1500 px (2:3) |
| `facebook-square.html` | Facebook post | 1080 × 1080 px (1:1) |
| `job-card.html` | Job announcement card | 1080 px wide |
| `infographic.html` | Step-by-step infographic | 1080 px wide |

## Rules
- Use only the brand colours: navy `#0f2440`, blue `#2563eb`, light blue `#93c5fd`, white, slate text `#334155`.
- Never add a fake government logo or imply official endorsement.
- Never show a salary unless it is officially published — and never show a "guaranteed" earning amount.
- Keep the footer with the site name and URL on every graphic.
- Export PNG/JPG at the stated size before posting.
