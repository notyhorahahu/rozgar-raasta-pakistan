# Image Sources — Rozgar Raasta Pakistan

(https://www.pexels.com), downloaded 27 Nov 2026 and resized/cropped to exactly
1200×800 JPEG (quality ~85, each under 200 KB) with FFmpeg. No AI-generated
images are used anywhere on the site.

required). Attribution is recorded here on file anyway, as good practice.

portrait crops of the old hero/category images and were left untouched.
